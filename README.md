# 中国历代行政区划和政治制度变迁 · 明代卷

一个以「历史地图计划 / 大明舆图」为参考的交互式历史地图原型，当前聚焦明代（1368—1644）。

## 快速开始

直接打开明代详图：

```text
app/index.html
```

朝代章节总览：

```text
app/chapters.html
```

左上角「明」印章可进入朝代章节选择；目前各朝先接入政权疆域与政权切换，行政层级将继续逐章细化。

页面所需的数据、图标、人物画像和 MapLibre 均已本地化，无需安装依赖；也可以起本地服务器：

```powershell
cd app
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 当前功能

- 1368—1644 连续年份时间轴，按年号分段，带精确指针、播放和逐年前后
- 明代府、州、县点位与县级视觉重建面（省界、府/州分色、县级边界）
- 56 条明代重大事件，事件图标在地图、时间轴、侧栏统一
- 同期官制树：中央官制 + 地方官制 + 品级徽章
- 同期人物：中央/地方政治人物卡片，可打开生平与历任官职
- 山脉图层：山峰图标 + 历史山名（黑体斜体）
- 现代省界虚线参考、历史事件标记、省/府/州/县名称开关
- 左右侧栏可拖动调整宽度

## 数据与来源

- 明代府界/省界：CHGIS V6 1600 年府级多边形（学术非商用；已做平面分区去重叠），来源 Harvard Dataverse
- 明代府州县点位与统计：开源项目「历史地图计划 / 大明舆图」（非商业学术研究与教育使用许可）
- 早期章节底图：heyyybingo/china-historical-atlas 的历代政权疆域数据（仅作章节总览）
- 历史地图集底本：谭其骧主编《中国历史地图集》
- 人物画像：Wikimedia Commons / 相关公开资料；缺画像者用首字占位
- 图标：部分来自 Lucide（ISC），部分由用户提供

> 历史示意图，非现代行政地图；不作为导航、测绘或主权表达依据。
> 县级面是「1600 年县治 + 现代县界」的视觉重建，并非逐县逐年考证边界。
