# 中国历代行政区划和政治制度变迁 · 明代卷

直接打开 `index.html` 即可。页面数据、MapLibre 库均为本地文件，无需安装依赖。

## 功能

- 1368—1644 年份时间轴（拖动/播放/逐年前后），按年号分段；带精确指针
- 明代 1600 年府、州、县点位（2 京/留都、13 布政使司、159 府、249 州、1155 县）
- 县级视觉重建面：现代县界 + 历史县治；省界深、省内府/州分色
- 大事面板：56 条明代政治、区划、军事、官制事件；事件图标在地图/时间轴/侧栏统一
- 侧边栏同期官制树：中央官制 + 地方官制 + 品级徽章 + 同期人物（可点开生平与历任官职）
- 点击/搜索地名查看详情、下级单位、户口赋税；选中府/州/县时整片高亮
- 图层开关：山脉、今省界、历史事件、省名/府名/州名/县名、卫所、羁縻等
- 山脉：山峰图标 + 历史山名（黑体斜体，长山脉字号和字距更大）

## 深链

```text
index.html?year=1600&unit=fujian-min-county
```

## 注意

- 行政区划底图以万历二十八年（1600）为基准；时间轴按年号分段，并在云南建省（1382）、贵州建省（1413）、郧阳设府（1476）等节点切换县级重建底图。县级面为视觉重建，不是逐县逐年考证边界。
- 数据来自开源项目「历史地图计划」，历史数据为非商业学术/教育使用许可；公开或商用前请确认授权。
- 历史示意图，非现代行政地图。
